📋 PROCEDURA COMPLETA - PASSO PER PASSO

╔══════════════════════════════════════════════════════════════════════════╗
║  FASE 1: APRI IL TERMINALE SUL TUO COMPUTER                             ║
╚══════════════════════════════════════════════════════════════════════════╝

📍 Windows:
   1. Premi tasto Windows
   2. Digita "cmd" o "PowerShell"
   3. Premi INVIO

   Vedrai qualcosa tipo:
   C:\Users\TuoNome>

📍 Mac:
   1. Premi Cmd + Spazio
   2. Digita "Terminal"
   3. Premi INVIO

   Vedrai qualcosa tipo:
   username@MacBook ~ %

📍 Linux:
   1. Premi Ctrl + Alt + T
   oppure cerca "Terminal" nelle applicazioni

   Vedrai qualcosa tipo:
   username@computer:~$

╔══════════════════════════════════════════════════════════════════════════╗
║  FASE 2: DECIDI DOVE SALVARE IL PROGETTO                                ║
╚══════════════════════════════════════════════════════════════════════════╝

Scegli una cartella dove vuoi salvare il progetto.
Esempio: Documenti, Desktop, una cartella "progetti", ecc.

Windows:
    cd C:\Users\TuoNome\Documenti
    # oppure
    cd Desktop

Mac/Linux:
    cd ~/Documents
    # oppure
    cd ~/Desktop
    # oppure
    mkdir ~/progetti
    cd ~/progetti

╔══════════════════════════════════════════════════════════════════════════╗
║  FASE 3: SCARICA IL CODICE DA GITHUB                                    ║
╚══════════════════════════════════════════════════════════════════════════╝

⚠️  Questo è l'UNICO momento in cui usi GitHub!
    Stai scaricando il codice SUL TUO COMPUTER.

Nel terminale, digita:

    git clone https://github.com/mario1967-gala/Mario-Galasso.git

Cosa succede:
    ✓ Git scarica il codice da GitHub
    ✓ Crea una cartella "Mario-Galasso" SUL TUO COMPUTER
    ✓ Il codice ora è sul tuo computer, non più solo su GitHub

Vedrai:

❓ DOMANDE FREQUENTI

Q: "Devo avere GitHub aperto nel browser?"
A: NO! GitHub serve solo per scaricare il codice con git clone.
   Dopo averlo scaricato, puoi chiudere GitHub.

Q: "L'applicazione va online?"
A: NO! Gira solo sul TUO computer. È accessibile solo da te su localhost.

Q: "Devo pagare GitHub?"
A: NO! GitHub è gratuito e lo usi solo per scaricare il codice.

Q: "Se chiudo il terminale, l'app continua a funzionare?"
A: NO! Devi tenere il terminale aperto mentre usi l'app.

Q: "Come faccio ad aprire più terminali?"
A: Puoi aprire una seconda finestra del terminale se devi eseguire altri comandi.

Q: "Dove sono salvati i dati?"
A: Sul TUO computer, nella cartella Mario-Galasso/instance/didattica.db

🎓 ESEMPIO COMPLETO - COPY & PASTE

Apri il terminale e copia questi comandi uno alla volta:

    # 1. Vai nella cartella documenti (o dove preferisci)
    cd ~/Documents    # Mac/Linux
    cd C:\Users\TuoNome\Documents    # Windows

    # 2. Scarica il codice da GitHub
    git clone https://github.com/mario1967-gala/Mario-Galasso.git

    # 3. Entra nella cartella
    cd Mario-Galasso

    # 4. Passa al branch corretto
    git checkout claude/high-school-class-management-011CUZ8aJ7hnNBgABX1RahdM

    # 5. Installa dipendenze
    pip3 install -r requirements.txt

    # 6. Popola database
    python3 seed_data.py

    # 7. Avvia applicazione
    python3 run.py

    # 8. Apri browser su: http://localhost:5001
