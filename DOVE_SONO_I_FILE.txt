❓ PROBLEMI COMUNI

╔═══════════════════════════════════════════════════════════════════════╗
║  "Non vedo i file" / "Cartella vuota"                                ║
╚═══════════════════════════════════════════════════════════════════════╝

1. Controlla di essere nella directory corretta:

   pwd                    (Linux/Mac)
   cd                     (Windows)

   Dovresti vedere: /percorso/Mario-Galasso

2. Controlla il branch git:

   git branch

   Dovresti vedere: * claude/high-school-class-management-011CUZ8aJ7hnNBgABX1RahdM

3. Passa al branch corretto:

   git checkout claude/high-school-class-management-011CUZ8aJ7hnNBgABX1RahdM

╔═══════════════════════════════════════════════════════════════════════╗
║  "Comando 'python' non trovato"                                      ║
╚═══════════════════════════════════════════════════════════════════════╝

Prova con python3:

    python3 run.py

╔═══════════════════════════════════════════════════════════════════════╗
║  "ModuleNotFoundError" o errori di import                            ║
╚═══════════════════════════════════════════════════════════════════════╝

Le dipendenze non sono installate:

    pip3 install -r requirements.txt

╔═══════════════════════════════════════════════════════════════════════╗
║  "Porta 5000 già in uso"                                             ║
╚═══════════════════════════════════════════════════════════════════════╝

Modifica run.py alla riga finale:

    app.run(debug=True, host='0.0.0.0', port=5001)

Poi usa: http://localhost:5001
